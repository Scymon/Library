# Hero BG Design Library

A comprehensive library of **100 animated background effects** for hero sections. Simply add a CSS class to activate stunning, performant JavaScript animations.

## Features

- ✨ **100 Unique Animations** - From particle networks to fractal flames
- 🎨 **Zero Configuration** - Just add a CSS class and go
- ⚡ **High Performance** - Optimized canvas rendering with requestAnimationFrame
- 🎯 **Customizable** - Configure via data attributes
- 📱 **Responsive** - Automatically adapts to container size
- ♿ **Accessible** - Respects prefers-reduced-motion
- 🔧 **Modular** - Use individual animations or the whole library

## Quick Start

### 1. Include the Library

```html
<!-- CSS -->
<link rel="stylesheet" href="dist/hero-bg-design.css">

<!-- JavaScript -->
<script src="dist/hero-bg-design.js"></script>
```

### 2. Add a Class to Your Element

```html
<div class="hero-bg-particle-networks">
  <h1>Your Content Here</h1>
  <p>The background animates automatically!</p>
</div>
```

That's it! The animation starts automatically.

## Customization

Customize animations using data attributes:

```html
<div class="hero-bg-particle-networks"
     data-hero-bg-particle-count="150"
     data-hero-bg-max-distance="200"
     data-hero-bg-particle-color="#ff6b6b">
  <h1>Customized Animation</h1>
</div>
```

### Common Options

Each animation supports different options. Common ones include:

- `data-hero-bg-speed` - Animation speed multiplier
- `data-hero-bg-colors` - JSON array of colors
- `data-hero-bg-particle-count` - Number of particles
- `data-hero-bg-fps` - Target frames per second

## Advanced Usage

### Manual Control

```javascript
// Access the global instance
import heroBGDesign from 'hero-bg-design';

// Stop an animation
const element = document.querySelector('.hero-bg-particle-networks');
heroBGDesign.stop(element);

// Start it again
heroBGDesign.start(element);

// Destroy completely
heroBGDesign.destroy(element);

// Destroy all animations
heroBGDesign.destroyAll();
```

### Programmatic Creation

```javascript
import { getAnimation } from 'hero-bg-design';

const element = document.querySelector('#my-hero');
const ParticleNetworks = getAnimation('hero-bg-particle-networks');

const animation = new ParticleNetworks(element, {
  particleCount: 100,
  maxDistance: 150,
  particleColor: '#4ECDC4'
});

animation.start();
```

## Browser Support

- Chrome/Edge 90+

- Safari 14+

Requires `<canvas>`, `ResizeObserver`, and `requestAnimationFrame` support.

## Performance Tips

1. Use one animation per page for best performance
2. Animations automatically pause when element is out of view
3. Set `data-hero-bg-fps="30"` for lower-end devices
4. Animations respect `prefers-reduced-motion` setting
